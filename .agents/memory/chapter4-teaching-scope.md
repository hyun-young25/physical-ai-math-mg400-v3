4장은 기존 목차 ‘운동학 종합과제: 픽앤플레이스’의 단일 MG400·작업물 한 개를 대상으로 학생이 좌표·운동학 관계를 적용하여 동작열을 설계하는 수업이다. 공정 운영 시연이 주목적이 아니다.

**Why:** 사용자가 4장의 교육 목적과 구현 범위를 명시했다.

**How to apply:** 과제→관계→학생 명령·예상값→학생 명령 DT 실행→TCP·물체 관찰→비교·원인 설명→수정·재실행·새 조건의 흐름을 유지한다. 안내 기본, 높이·접근 조정, 전체 직접 설계의 순서이며 도전·새 조건의 완성 답안을 선노출하지 않는다. 학생 설명은 자동채점하지 않고 교사 검토 대기로 기록한다. DT 계산을 실측·안전성 검증으로 표현하지 않는다.

컨베이어·두 로봇·2×2 포장은 삭제하지 않되, 종합설계 완료 후 접이식 ‘확장 공정’으로만 제공한다. 새 상위 메뉴를 만들지 않고 1~3장, 다른 장 디자인, 기존 기록 형식, 로봇 모델은 변경하지 않는다.

**Why:** 사용자가 기존 교육 내용과 로봇 모델 보존을 요청했다.

**How to apply:** 확장 기능이 본 수업보다 먼저 노출되지 않도록 하고, 공통 시각화 보완은 새 수업 조건에서만 적용한다. 실장비 연결 중·연결 후에는 DT 실행을 막으며 정지·HOME·초기화·메뉴 이동 뒤 지연 프레임이 다시 적용되지 않아야 한다.
