---
name: MG400 두 가지 실습 방식
description: 장비 없는 기본 실습과 같은 학생 계획의 실측 실행을 구분하는 제품 요구.
---

사용자가 원하는 두 가지는 “실제 로봇 없이 화면에서 실습”과 “우리 콘텐츠로 실제 MG400 제어”이다. 기존 수업·디자인·7단계와 학생이 작성한 좌표·계획을 보존하며, 장비·DobotStudio 없는 가상 실습이 기본이다.

**Why:** 사용자가 “내가 원하는게 이거 두개야”라고 목적을 명시했다.

**How to apply:** 실제 실행은 같은 학생 계획의 별도 실행으로 취급한다. 모드 변경·연결만으로 이동/흡착하지 않는다. 가상·모의·실측을 혼동시키거나 실측 누락을 가상값으로 보충하지 않는다. TCP·DO만으로 물체 집기/놓기를 실측 성공이라 판정하지 않는다. 모의 시험 통과와 물리 장비 검증을 분명히 구분한다.

사각형은 예외적으로 시작 전에 한 번 승인하는 가상 → 실제 연속 실행을 제공한다. “정답 수치 입력 → 가상 사각형 그리기 완료 → 같은 학생 좌표로 실제 장비가 사각형 그리기”이며, 두 실행 사이에 별도 화면/모드 전환·실제 실행 버튼·비교/성찰 클릭을 요구하지 않는다. 기존 가상 전용 실행도 유지한다.

**Why:** 사용자가 가상 사각형 뒤 장비가 이어 그리지 않는 것이 문제라고 정정하며 이 연속 흐름을 명시했다.

**How to apply:** 승인은 해당 답안과 경로의 1회에만 귀속한다. 실제 가상 완주·닫힘·복귀 후 물리 직전 안전 조건을 다시 검사하고, 변경/실패/중단은 승인 폐기 후 새 시작을 요구한다. 재연결·오류 해제·중복 완료 통보로 실행하지 않는다. 공통 중단도 아직 물리 명령이 없는 가상 단계의 후속 실행을 취소해야 한다. 비교/성찰은 두 실행 후 결과에서 계속하고 실측 DT와 가상 경로를 섞지 않는다.

기초수학에서 가상 완료는 실제 실행 자격을 없애지 않는다. 같은 최초 답·근거를 재사용하는 실제 이동은 학생의 별도 요청과 실행 승인이 필요하며, 이전 실행은 보존한다. 출발 위치가 문제와 다르면 현재값과 필요한 출발값을 안내하고 자동 이동이나 정답 변경으로 보정하지 않는다.

**Why:** 사용자가 정답인데 장비가 움직이지 않는 문제를 설명하면서 가상 완료 후 같은 답의 명시적 실제 실행, 원본 보존, 출발 위치 불일치 시 자동 보정 금지를 요구했다.

**How to apply:** 실행 가능 여부와 수학 문항 완료 여부를 구분하고, 재실행·취소·차단도 최초 예측을 덮어쓰지 않게 처리한다.

시작 기준 좌표가 있는 과제는 사용자가 명시적으로 누르는 ‘과제 시작점으로 이동’으로 준비할 수 있어야 한다. 이는 자동 보정의 허용이 아니다. 선택한 과제의 실제 시작점을 사용하고, 일부 축만 정해진 경우 나머지는 현재값을 유지하며, 과제 실행·채점·예측 입력·기존 기록과 분리한다.

**Why:** 사용자가 실측 로봇이 수업의 출발점과 달라 바로 과제를 수행할 수 없다고 설명하며 별도 시작점 이동을 요청했다.

**How to apply:** 실장비 이동에는 기존 준비·서보·좌표계·작업 범위 검사와 목표 X/Y/Z/R·이동 방식의 별도 승인을 유지한다. Z=0 같은 예시가 검증된 범위 밖이면 차단하고 예시 좌표나 범위를 임의로 바꾸지 않는다. 시작점 준비 기능의 개발 검증에는 실장비를 접속하거나 이동하지 않는다.

기능 구현과 가상·모의 검증을 먼저 완료하고 실물 연결 확인은 나중에 별도로 진행한다. 로봇 IP나 실물 연결을 사용자에게 요구하며 기능 구현 작업을 중단하지 않는다.

**Why:** 사용자가 “로봇은 안열결 되어있는데 일단 기능만 먼저 넣어줘. 나중에 확인해보자”라고 명시했다.

**How to apply:** 기능 개발의 검증은 고립된 가상 환경과 명확히 표시한 모의 통신으로 진행한다. 실물 확인을 기다리는 상태로 남은 구현·검증을 미루지 않는다.

실시간 측정 화면의 표시를 정리할 때는 원본 실측 정밀도·수신·학습 기록·CSV 저장을 보존하고 화면 표시만 정리한다. 준비 설정 입력 중에는 실측 갱신 때문에 포커스·커서·스크롤 위치가 바뀌지 않아야 한다.

**Why:** 사용자가 긴 실측 소수와 반복 줄바꿈 문제를 설명하며 이 보존 조건을 명시했다.

**How to apply:** 숫자 반올림은 표시 계층에만 적용한다. 장비 없는 재현 데이터로 값의 길이·부호·seq·최신/지연 상태를 바꾸며 보통 폭과 좁은 폭에서 배치와 입력 상태를 검증한다.
