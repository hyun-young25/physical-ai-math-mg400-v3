---
name: Git 제공자 인증과 연결 카드
description: GitHub 소스 제어 연결의 메타데이터와 실제 Git 인증을 구분한다.
---

Git 제공자 연결은 일반 앱 API 연결과 달리 워크스페이스의 Git CLI에 자동 인증을 제공한다. 연결 상태가 healthy 또는 active라고 나와도 실제 fetch가 인증 오류로 실패할 수 있으므로 성공 여부는 Git 응답으로 판단한다.

**Why:** 연결 메타데이터와 실제 Git 인증 결과가 달랐으며, 일반 재인증 카드는 연결을 인식하지 못하고 일반 연결 카드는 connectorId가 없다는 검증 오류를 반환했다.

**How to apply:** 기존 연결 안내대로 Git CLI를 사용하고 인증 거부 시 비밀값을 직접 읽거나 원격 URL에 넣지 않는다. 연결 카드가 Git 제공자 연결을 처리하지 못하면 반복 요청하지 말고, 공식 문서에서 확인한 계정 Connected Services의 GitHub 재연결 경로를 안내한다. 원격 확인에 실패하면 충돌 여부나 동기화 완료를 주장하지 않는다.
