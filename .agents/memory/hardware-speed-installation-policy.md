---
name: 실장비 속도와 설치 프로필 확인 원칙
description: 공통 저속 적용, 사람 확인 재사용, 현장 작업 범위와 원시 좌표의 안전 경계.
---

수동·과제·과제 시작점 이동은 같은 실제 적용 속도를 사용한다. 새 설정 기본값은 5%, 웹 조절은 기존 1~20% 범위다. 변경 예정 값과 적용 값을 분리하고 정지 상태에서 명시적으로 적용하며, 성공 응답 전이나 실패 후에 적용 완료라고 표시하지 않는다. 실행 확인에는 실제 적용 설정을 사용하고 기존 승인 절차를 유지한다.

**Why:** 사용자가 실제 과제 속도가 너무 빠르다고 보고하고, 웹에서 쉽게 저속을 바꾸되 미적용 값을 실제 속도처럼 표시하지 말라고 요청했다.

**How to apply:** 속도 비율은 TCP mm/s 실측이 아니다. 현재 PC에서 실행 중인 브리지는 웹 변경으로 자동 교체되지 않으므로 다운로드 소스 변경과 현장 반영·실기 검증을 구분한다. 실장비 접속·이동 없이 모의 통신과 오프라인 명령 검사를 사용한다.

설치 프로필은 사람이 확인한 설치 값과 출처·대상에 한정된 기록이지 센서 검증이나 현재 세션의 자동 승인서가 아니다. 같은 활성 연결의 동일 설치 확인은 재사용하되 새 연결은 저장 요약을 보고 사람이 설치·주변 조건의 동일함을 명시적으로 재확인한다. 설정·대상·출처 변경이나 정지 불확실 상태는 관련 확인을 다시 요구한다. 모의 확인을 실장비 확인으로 재사용하지 않는다.

**Why:** 사용자가 반복 확인을 줄이되 무조건 일괄 체크하거나 장애물·공구·배선·교정을 거짓 자동 검증하지 말라고 요청했다.

**How to apply:** 프로필 불러오기와 적용은 별개다. 저장된 확인의 효력을 다른 PC·로봇·출처에 자동 확장하지 않는다. 순수 속도 조절 때문에 변경 없는 설치 체크를 전부 다시 요구하지는 않는다.

작업 범위는 현장 검증 프로필을 기준으로 하며 제조사 최대 도달 범위를 직육면체 안전 범위로 간주해 확대하지 않는다. 현재 실측·과제 시작점·단계별 목표를 원시 좌표로 비교하고 초과 축·값·경계·단계를 안내한다. Z=0 같은 정확한 경계도 실행 전에 알려야 한다.

**Why:** 사용자가 현장 좌표 정보 없이 작업 범위를 임의 확정하거나, 반올림 때문에 차단되는 값을 안전 검사 완화로 해결하지 말라고 요청했다.

**How to apply:** 표시 반올림, 도착 허용 오차, 작은 epsilon을 작업 범위 확장에 쓰지 않는다. 설치 정보가 없으면 User 원점·Tool/TCP 교정·지그·바닥·배선 여유와 검증한 각 축 경계를 확인하도록 안내한다. 좌표 끝점 검사를 전체 궤적 무충돌 인증처럼 설명하지 않는다.
