---
name: MG400 연결 대상 고정
description: 사용자가 지정한 단일 교육용 MG400 IP와 수동 연결 원칙
---

MG400 연결 대상 IP는 `192.168.1.6`으로 고정한다. 안내·연결 화면에서는 수정할 수 없으며 이전에 저장된 다른 주소도 연결 대상으로 사용하지 않는다.

**Why:** 사용자가 교육용 MG400의 연결 주소를 고정하고 새로고침 후에도 동일하게 유지하도록 요청했다.

**How to apply:** PC 브리지 주소와 로봇 IP를 구분한다. 가상 실습·모의 통신·실장비 확인 절차는 유지하고 자동 연결이나 자동 동작을 추가하지 않는다.

사용자는 로봇 전원 재시작 후 실제 MG400 연결이 정상 작동한다고 확인했다. 이는 사용자 현장 확인이며, 에이전트가 실장비를 직접 검증했다는 뜻은 아니다.
