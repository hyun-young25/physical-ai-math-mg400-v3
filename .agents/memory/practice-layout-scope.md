---
name: 실습 화면 배치 원칙
description: 로봇·과제·안내 연결 영역의 동시 열람과 연결 상태 보존에 관한 사용자 요구
---

넓은 화면에서는 로봇, 학습 과제, 안내·연결을 동시에 읽을 수 있고 필요한 영역이 독립적으로 스크롤되어야 한다. 좁은 화면에서는 읽을 수 있는 폭과 모든 내용·버튼의 접근성을 유지한다. 안내·연결을 닫으면 학습 화면 공간을 다시 확보한다.

**Why:** 사용자가 안내·연결이 2-1 과제의 표와 버튼을 덮는 문제를 보고했으며 다른 과제에서도 같은 문제를 없애 달라고 요청했다.

**How to apply:** 패널 열기·닫기와 화면 크기 변경은 실제 연결, 준비 설정, 기록, 과제 진행을 초기화해서는 안 된다. 배치 수정의 확인에는 실장비 연결이나 이동을 실행하지 않고 격리된 모의 통신을 사용한다.

2-1 좌표축과 이동 방향에서도 2-2와 동일한 기존 AI 챗봇 진입 버튼·대화창을 제공하고, 현재 단원·문항의 맥락으로 동작해야 한다. 챗봇과 과제·안내 연결 영역은 함께 접근할 수 있어야 한다.

**Why:** 사용자가 2-1에서 기존 챗봇이 보이지 않는 문제를 지적하며 동일한 챗봇 제공과 현재 과제 맥락, 시작점 이동·배치·과제 진행·연결·준비 상태 보존을 요구했다.

**How to apply:** 튜터를 열고 닫거나 단원을 전환하는 처리를 로봇 실행·연결 초기화·과제 초기화와 연결하지 않는다. 챗봇이 차지한 뒤 남는 학습 영역의 실제 폭으로 배치를 판단하고, 작은 화면에서도 학습 영역과 입력·닫기 버튼에 각각 접근할 수 있게 한다.

챗봇을 열어 둔 채 왼쪽 로봇·학습 화면의 관찰, 클릭, 과제 입력과 채팅 복귀가 가능해야 한다. 챗봇은 바깥 영역을 덮거나 입력을 잠그는 모달이 아니며 최소화·닫기를 명확하게 제공한다. 실제 로봇 실행 확인창만은 승인·취소와 중복 실행 방지를 그대로 유지한다.

**Why:** 사용자가 챗봇을 연 뒤 왼쪽 화면을 클릭할 수 없다고 보고하며 비모달 동시 조작과 실제 실행 승인 보존을 명시했다.

**How to apply:** 배치의 사각형 비교만으로 클릭 가능하다고 판단하지 않는다. 강제 클릭 없이 왼쪽 입력·선택·시점 버튼과 채팅 복귀·최소화·닫기를 시험하고, 실행 확인창이 떠 있을 때는 반대로 채팅보다 우선하는지 격리된 모의 환경에서 확인한다.

튜터는 화면 높이를 충분히 활용하되 제목·닫기와 입력·전송은 항상 접근 가능하게 하고, 긴 대화는 내부에서 스크롤한다. 작은 화면의 키보드로 높이가 줄어들면 부가 영역보다 입력 조작을 우선한다.

**Why:** 사용자가 튜터가 세로로 너무 짧다고 지적하며 화면 크기와 키보드에 맞는 높이, 고정된 제목·입력 조작, 내부 대화 스크롤을 요청했다.

**How to apply:** 튜터 크기 조정은 기존 대화/학습/연결 상태를 초기화하지 않는다. 가시 영역 축소와 이동을 함께 검사하고 실제 휴대전화 검증과 모의 키보드 검증을 구분해 보고한다.
