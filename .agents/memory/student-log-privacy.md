---
name: 학생 학습 로그의 식별·연구 원칙
description: 아이디만으로 학습하되 과거 자료는 비공개, 익명 자료 귀속 금지, 과정 로그·시험 구분과 단일 소유자 권한.
---

기존 익명 기록은 특정 학생에게 임의로 귀속하지 않는다. 계정별 과정 로그는 최초 예측·이전 시도를 보존하며 해당 활동에서 실제 발생한 행동만 기록한다. 가상·모의 결과를 실측으로 바꾸거나 설명을 이해도 시험 성적으로 취급하지 않는다.

**Why:** 사용자가 학생별 장기 기록 수집을 요청하면서 익명 자료의 임의 귀속·예측 덮어쓰기·추가 시험지 생성을 명시적으로 금지했다.

**How to apply:** 향후 마이그레이션·내보내기·평가 기능을 추가할 때도 원본과 출처를 보존하고 과정 자료와 별도 이해도 평가를 구별한다.

학생은 학생 아이디와 ‘학습 시작’만으로 즉시 콘텐츠를 사용한다. 가입·비밀번호·수업 코드·이메일 절차를 요구하지 않는다. 아이디는 로그 묶음 식별값이지 인증이 아니다. 같은 아이디 재입장도 서버·브라우저 과거 기록을 학생에게 복원하는 근거가 아니다. 학생에게 과거 기록·학생 목록·CSV를 제공하지 않는다. 공용 PC에서 미전송 기록은 원래 학생 방문의 식별값을 유지하며 다음 학생에게 귀속하지 않는다.

**Why:** 사용자의 최신 요구가 이전 비밀번호 재입장·가입·수업 코드 방식을 명시적으로 대체했다. 접근은 단순하게 하되 공용 PC 기록 혼합과 아이디만으로 과거 자료 접근은 금지했다.

사용자가 실제 브라우저에서 새 아이디 하나로 MG400 학습 화면과 저장 상태가 표시되는 것을 확인했다. 이 학생 입장 방식을 승인했으므로 다시 만들지 않고, 기존 관련 검증을 중심으로 실제 오류만 수정한다.

**How to apply:** 학생 UI·캐시·재접속·전송 큐를 바꿀 때 식별과 조회 권한을 분리한다. 아이디별 집계는 동일 인물임을 증명하지 않는다는 점을 지킨다.

교수자 전체 조회와 CSV는 프로젝트 소유자 한 사람의 검증된 Replit 계정 인증에만 허용한다. 최초 로그인·첫 방문·교수자 버튼·기존 커스텀 교사 계정으로 권한을 부여하지 않는다. 신뢰할 수 있는 소유자 확인 설정이 없으면 차단하고 미완료를 명확히 보고한다. 비밀번호나 공유 비밀을 새로 발급·전달·노출하지 않고 기존 자격 증명·기록·계정을 변경·삭제하지 않는다.

**Why:** 사용자가 이 프로젝트의 단일 소유자 권한 모델과 기존 자료·자격 증명 보존을 명시했다.

**How to apply:** 소유자 자동 승격이나 공개 관리자 가입·초기 설정 경로를 추가하지 않는다. 인증·권한 검증은 실제 학생 자료 대신 명시적인 테스트 자료로 수행한다.
