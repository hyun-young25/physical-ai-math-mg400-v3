# 수업 투입용 5주 운영안

이 문서는 현재 구현된 공간기하·운동학 콘텐츠를 전문대·4년제 공학계열 수업에 적용하기 위한 압축 운영안이다. 목표는 계산 정답만 확인하는 것이 아니라, 학생이 조건을 읽고 수학적으로 구조화한 뒤 DT에서 실행하고 결과를 해석·수정하는 과정을 남기는 것이다.

## 권장 운영

- 기본: 5주, 주 1회 90~120분
- 4주 압축: 1·2주차를 통합
- 6주 이상 운영 가능: 마지막에 FK/IK·픽앤플레이스 종합 과제를 확장
- 각 차시 공통 순서: 과제 이해 10분 → 예측·근거 20분 → DT 실행 25분 → 결과 비교 20분 → 수정·재실행 15분 → 기록 내보내기 5분
- 실장비는 DT 과제를 통과한 뒤 선택적으로 사용한다. DT 결과와 장비 텔레메트리는 같은 의미의 측정값으로 표시하지 않는다.

## 주차별 진행

| 주차 | 학생이 해결할 문제 | 앱 활동 | 수업 산출물 |
| --- | --- | --- | --- |
| 1주차 | 절대위치와 상대변화량을 구분할 수 있는가? | 기초수학 1번의 Z=20→60, ΔX=0·ΔY=0·ΔZ=40, MoveL 예측·수학 확인 | 최초 답, 계산 근거, 정오 피드백 |
| 2주차 | 세 축 변화량·부호·거리를 경로와 연결할 수 있는가? | Δp, 3차원 거리, 직선/관절 이동 선택 및 새 조건 전이 | 벡터 계산, 거리 계산, 명령 선택 이유 |
| 3주차 | 링크 길이를 cos·sin 성분으로 분해할 수 있는가? | 링크 성분 문제와 2-1 링크 성분 화면 비교 | 성분값, 각도 변화에 대한 예측 |
| 4주차 | 두 링크 성분을 더해 TCP를 예측할 수 있는가? | 2링크 TCP 순기구학·각도 변경 조건·FK/IK 확인 | TCP 예측, DT 결과, 오차 해석 |
| 5주차 | 같은 작업을 다른 표현으로 실행하고 수정할 수 있는가? | 2-2 물체 옮기기: 절대좌표·상대좌표 각각 실행 → 비교 → 새 조건 Z=30→60 재예측·재실행 | 두 방식 기록, 설명, 수정 근거, 최종 재실행 |

## 4주 압축안

1주차에 위치·변화량과 벡터·거리를 함께 진행하고, 2주차부터는 삼각비·링크 성분, 2링크 TCP, 물체 옮기기 순서로 진행한다. 1주차 문제를 모두 끝내려 하기보다 Z=20→60 대표 문제를 반드시 완료하고 나머지는 개별 보충으로 남긴다.

## 학생에게 요구할 최소 증거

1. 조건에서 변하는 축과 유지되는 축을 표시한다.
2. 최초 예측값과 그렇게 생각한 근거를 제출한다.
3. DT 실행 결과와 목표의 차이를 확인한다.
4. 틀린 경우 무엇을 어떻게 바꿨는지 쓴다.
5. 새 조건에서 답을 처음부터 다시 계산하고 재실행한다.

주관식 설명은 현재 자동으로 개념의 진위를 확정하지 않는다. 앱은 입력·관계 기반 피드백과 수정 요청을 제공하고, 교사는 내려받은 기록을 근거로 설명의 타당성을 확인한다.

## 수업 전 점검

- [ ] 기초수학 탭에서 첫 문제의 단계별 입력과 빨강/초록 피드백 확인
- [ ] 마지막 입력 저장 후 2-1 좌표축·이동 방향으로 연결 버튼이 보이는지 확인
- [ ] 2-1 완료 후 2-2 절대·상대 이동으로 넘어가는지 확인
- [ ] 절대좌표 운반과 상대좌표 운반이 모두 완료되는지 확인
- [ ] 비교표에서 들어 올리기 구간이 절대 Z=60, 상대 ΔZ=40으로 기록되는지 확인
- [ ] 새 조건 화면이 Z=30→60, 상대 ΔZ=30을 요구하는지 확인
- [ ] 학습 기록 내려받기와 새로고침 전 기록 보관 방법 안내
- [ ] 실장비 수업에서는 DT 통과 후 별도 실행하고, 장비 좌표를 독립 측정값이라고 설명하지 않기

## 개발 완료 판정

수업 투입 전에는 새 단원 추가보다 다음 흐름의 회귀 검증을 우선한다.

기초 예측 → 수학 확인 → 2-2 절대 실행 → 상대 실행 → 비교·설명 → Z=30 새 조건 예측 → DT 실행 → 수정 기록

이 흐름이 한 학생 화면에서 막힘없이 이어지고 기록이 남으면, 현재 범위는 4~5주 수업에 투입할 수 있는 최소 완성 상태다. 회전행렬·자코비안·상태공간·비전 좌표변환은 후속 확장으로 분리한다.
