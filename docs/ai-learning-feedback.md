# MG400 맞춤 학습 피드백 운영 안내

## 설정

- 운영자가 프로젝트의 Replit Secrets에 `OPENAI_API_KEY`를 추가한다. 학생은 키를 입력하지 않는다.
- 키는 서버에서만 읽는다. 브라우저 번들, 요청 본문, 학습 기록, 서버 로그에 넣지 않는다.
- 키가 없으면 별도 설정 없이 규칙 기반 기본 안내로 학습을 계속한다.
- 모델은 OpenAI `gpt-5-mini`, 서버의 Chat Completions 연결을 사용한다.
- 공개 게시·재게시하지 않는다. 이전 배포 승인은 취소되었으며 기존 공개 사이트는 유지한다.

## 기본 체험 모드와 실제 GPT 선택

- 새 탭·새로고침은 항상 `체험 모드 · 기본 힌트`로 시작한다. 외부 AI 및 피드백 API를 호출하지 않고 현재 문제의 입력·기존 판정·지원/도전 단계·시도·가상 실행 자료로 즉시 응답한다.
- 체험 대화는 해당 컴포넌트의 탭 메모리에만 보관한다. 학습 서버·기존 AI 활동 저장소에 쓰지 않으며 최초 예측이나 기존 기록을 변경하지 않는다. 원래 수학 학습 기록은 기존 방식대로 유지한다.
- 범위 밖 자유 질문은 답을 지어내지 않고 현재 과제에서 제공하는 도움을 안내한다. 입력 변경 후에는 다시 질문하면 갱신된 입력을 사용하며 이전 답변은 당시 입력 기준으로 남는다.
- 운영자가 대화창의 ‘응답 방식’에서 `실제 GPT · 운영자 선택`을 명시적으로 선택하면 기존 서버 OpenAI 연동을 사용한다. 선택 자체는 호출하지 않으며 질문·단계 확인부터 요청한다. 학생에게 키 등록이나 결제를 요구하지 않는다.
- 체험 대화와 GPT 대화는 분리하며 모드·입력·문제 변경 후 도착한 응답은 폐기한다. GPT 실패 시 기본 안내로 전환하고 출처를 구분한다. 실제 GPT 성공/크레딧 충전은 체험 기능 완료의 조건이 아니다.

## 적용 범위

기초 높이·벡터·거리·삼각비·링크 문항, 절대/상대좌표 비교와 상황 설계,
좌표 직접 적용, MoveJ/MoveL 경로 비교, FK/IK 및 공통 예측·결과 비교 화면에 적용한다.
기초수학은 단계별 확인·제출·실행 결과, 공통 학습은 예측 제출·결과 확인,
좌표 비교/설계는 제출·DT 결과 때 요청한다. 좌표 직접 적용은 입력과 단계가
자동으로 초기화되므로 결과 옆 비교 버튼으로 명시적으로 요청한다.
지원 화면의 오른쪽 아래 로봇 버튼으로 ‘AI 수학 튜터’를 열고 접을 수 있다.
기존 AI 피드백은 이 창으로 모으며 원래 수치 입력·정오 표시·실행 확인은 학습 화면에 유지한다.
‘힌트만 주세요’, 오답 판정 후의 ‘왜 틀렸나요?’, 실행 자료 확보 후의 ‘예상과 결과 비교’ 및
1,000자 이내 자유 질문을 지원한다. 같은 문제에서 실제 표시된 최근 대화 최대 8개를 전달한다.
문제 전환은 대화를 분리하고 입력·풀이·실행 자료 변경은 이전 요청을 무효화한다.
한국어 조합 중 Enter는 전송하지 않고 Shift+Enter는 줄바꿈한다.
입력할 때마다 자동 호출하지 않으며 AI 대기와 장애는 기존 학습을 차단하지 않는다.

실장비 지원은 기존 실행 버튼의 범위 그대로다. AI를 추가했다고
새 과제가 실장비를 지원하는 것은 아니다. 좌표 직접 적용·설계·비교는 DT 전용이다.

## 안전 경계

AI는 기존 판정·입력·이유·최초 예측·같은 문제의 최근 시도와 제공 힌트를 읽어
짧은 한국어 질문을 만든다. 출력은 텍스트만 표시하며 정답값, 채점 상태,
로봇 목표, 안전 검사, 승인 상태를 변경하는 코드 경로가 없다.
연결·초기 위치·측정 신선도·작업 범위·실행 승인·중복 실행 차단은 기존 제어 경로가 담당한다.
AI 요청 중에도 채점·실행을 기다리게 하지 않는다.

실행 자료는 완료/차단/취소, 출처, 확보된 전후 위치·좌표계·단위·측정 시점을 전달한다.
값이 없는 부분을 생성하지 않는다. 가상·시험용·실측·수학 계산을 구분하며
TCP 위치나 흡착 출력으로 물체 집기 성공을 확인할 수 없다.
물리 오차 원인에 관한 AI 설명은 측정으로 확인된 원인이 아니며 가능한 설명과 구별해야 한다.

## 개인정보와 기록

AI 요청은 학습 내용만 선택한다. 계정/학생 식별값, 이름 필드, 연락처 필드,
네트워크 주소·원본 패킷을 제외하고 이메일·전화번호 등 정형 개인정보도 가린다.
학생에게 자유 서술에 이름·연락처를 적지 않도록 안내한다. 임의 문장 속 모든 개인정보를
완벽히 찾아내는 장치는 아니므로 교사는 개인정보 없는 풀이 작성을 안내해야 한다.
서버의 방문 식별값 확인은 OpenAI 전송 전에 분리한다.

최초 답·이유와 실행 이력은 기존 기록에 그대로 둔다. 실제 GPT 선택 모드의 AI 활동은 별도 기록에
요청 시각·입력 스냅샷·원래 예측·시도 이력·출처·학생 질문·실제 제공 문장을 저장한다.
새 활동은 튜터 창이 열려 실제 표시된 질문/응답 쌍 또는 자동 힌트만 `displayed`로 저장한다.
진행 중·폐기·닫힌 창에서 아직 보지 않은 응답은 저장하거나 후속 대화에 포함하지 않는다.
과거 버전의 `requested`/`discarded` 기록은 삭제하지 않지만 제공된 힌트로 사용하지 않는다.
이전 학습 기록에 AI 활동을 소급 생성하지 않는다.
새 기록은 기존 전송 대기열을 통해 교사용 상세 기록·CSV로 전달된다.

## 제한과 오류 처리

- 서버 요청: 10초 제한. 브라우저: 12초 제한.
- 응답: 최대 700자. 시스템 지침은 3문장·500자 이내, 모델 생성 예산 1,200 토큰.
- 과도한 요청: IP당 분당 30회, 방문당 시간당 120회, 서버 프로세스당 하루 2,000회,
  동시 요청 4회. 초과 시 유료 호출 없이 기본 안내.
- 키 없음, 인증/서비스 오류, 사용량 제한, 시간 초과, 빈 응답·길이 초과는
  `rules` 기본 안내로 전환한다. `openai` AI 생성과 출처를 명확히 구분한다.
- 버튼 재시도만 제공하고 자동 재시도로 과금을 늘리지 않는다.
- 위 사용량 예산은 프로세스 메모리 기준이다. 서버 재시작 시 초기화되며 다중 인스턴스에서는
  인스턴스별로 계산된다. 운영자는 OpenAI 계정의 비용 한도도 별도로 설정해야 한다.
- 모델의 교육적 적절성과 실제 서비스 응답은 키 설정 후 별도의 실호출 점검이 필요하다.

## 실장비 없는 검증

`scripts/verify-ai-feedback.cjs`는 실제 UI에서 학습 HTTP와 GPT 응답을 가로채
창 열기/접기, 빈 이유·오답, 자유/후속 질문, 한국어 조합, 중복·늦은 응답,
문제별 대화 분리, 기본 안내·재시도, 가상 결과 비교, 모바일 비중첩,
실장비 미연결 차단과 기록 보존을 검증한다. 실제 OpenAI 호출은 하지 않는다.
`scripts/verify-foundation-motion.cjs`는 브라우저 내부의 protocol-v2 모의 통신으로
기존 실행 승인·작업 범위·오래된 측정·출발 위치·취소·중복 클릭을 검사한다.
두 스크립트는 실제 로봇 소켓이나 학습 서버 쓰기를 사용하지 않는다.

`scripts/verify-trial-tutor.cjs`는 새 브라우저의 시험 학생/학습 HTTP 가로채기로
체험 기본값, 입력 변경·기존 판정·추가 질문, 지원/도전, 정답 후 가상 이동과 비교,
문제 전환과 모바일 표시를 확인한다. 피드백 API 및 외부 AI 호출 0건,
체험 대화 저장·업로드 0건을 검사하며 실제 학생 기록·장비에 접근하지 않는다.
