# 학생 입장과 교수자 학습 로그

## 최초 교수자 설정

공개 웹 가입·학생의 역할 선택으로 교수자 권한을 만들 수 없습니다. 프로젝트 소유자는 자신의 비공개 작업공간에서 다음 순서로 초기 설정합니다.

1. Replit Secrets에 `LEARNING_OWNER_SETUP_SECRET`을 32자 이상의 충분히 무작위인 비밀로 설정합니다. 학생·다른 사용자에게 공유하지 않습니다.
2. 웹 **교사 초기 설정**에서 초기 설정 비밀로 인증하고 교수자 아이디·10~128자 개인 비밀번호와 확인을 입력합니다. 서버는 비밀을 비교한 뒤 최초 계정을 한 번만 생성합니다. 비밀번호는 salt+scrypt 해시로만 DB에 저장됩니다.
3. 비공개 작업공간 Shell에서 `pnpm --filter @workspace/api-server run setup-teacher`를 실행하는 대안도 있습니다. 입력은 화면에 표시되지 않습니다.
4. 최초 계정 생성 후 다시 생성하거나 기존 교수자 계정을 덮어쓸 수 없습니다. 초기 설정 비밀은 Secrets에서 제거할 수 있습니다.
5. 웹 화면의 **교사 로그인**으로 입장해 수업 코드와 수업 이름을 개설합니다.

소유자 인증은 소유자가 비공개 Secrets에 설정한 초기 설정 비밀을 통한 방식입니다. Replit 계정 SSO를 추가하거나 최초 웹 방문자를 자동 교수자로 승격하는 방식이 아닙니다. 비밀을 가지지 않은 교수자 선택·학생 계정·웹 방문자는 최초 설정을 할 수 없습니다.

Shell 명령은 해당 작업공간의 개발 DB에 적용됩니다. 게시 환경은 개발 DB와 별개이며, 개발 환경의 교수자·수업·테스트 데이터를 자동 복사하지 않습니다. 게시 후 해당 환경에도 Secrets를 설정한 뒤 게시 사이트의 **교사 초기 설정**을 한 번 진행합니다. 두 환경 초기 설정이 끝난 뒤 설정 비밀을 제거할 수 있습니다.

## 학생

- 첫 등록: **학생 입장 → 처음 등록**에서 교수자가 알려준 수업 코드, 학생 아이디, 10자 이상의 개인 비밀번호와 확인을 입력합니다.
- 재입장: 같은 수업 코드·아이디·비밀번호를 입력합니다. 아이디만으로는 기존 기록에 접근할 수 없습니다.
- 화면 위 **내 학습 기록**에서 서버에 저장한 자기 기록을 확인합니다.
- 상단 표시가 **서버 저장 완료**일 때만 서버 수신 확인을 받은 상태입니다. **전송 대기 / 실패**는 완료가 아닙니다.
- 수업 도중 네트워크가 끊어지면 학생별 브라우저 대기열에 보관하고 재연결 후 전송합니다. 브라우저 저장 용량까지 부족하면 실패를 표시하므로 창을 닫지 말고 연결 복구 후 다시 전송합니다.
- 공용 PC에서는 **나가기 · 학생 전환**을 사용합니다. 새 페이지·새로고침은 이전 서버 세션을 잠근 뒤 다시 입장을 요구합니다.
- 학생이 다른 기기로 옮겨도 서버에 이미 저장한 기록은 재입장 후 확인됩니다. 전송하지 못한 임시 기록은 원래 PC에서 같은 계정으로 입장해야 보낼 수 있습니다.
- 기존 익명 저장 자료를 특정 학생에게 자동으로 연결하지 않습니다.

## 교수자 조회·CSV

**교사 로그인 → 학습 기록**에서 자기 수업의 학생 목록, 최근 활동, 사건 수와 기록 원문을 확인합니다.

수업·학생·단원·날짜 필터를 적용하고 **현재 조건 CSV** 또는 **전체 CSV**를 선택합니다. 현재 조건은 화면에 표시한 페이지만이 아니라 모든 일치 기록을 내보냅니다. 전체는 이 교수자에게 허용된 모든 수업의 기록이며 다른 교수자 수업은 포함하지 않습니다.

UTF-8 BOM, CSV 인용과 줄바꿈 처리, 수식 문자열 방어를 사용합니다. 사건마다 최초 예측·수정·결과·지원·설명 개요가 있으며, 전체 중첩 값은 `항목 경로 / 항목 값`으로 펼칩니다. 큰 개요는 표시용으로 제한되지만 실제 값은 항목 행에 보존합니다. 30,000자가 넘는 단일 문자열은 문자 범위를 표시해 여러 행으로 나눕니다. 사건 한 건이 여러 CSV 행이 되므로 CSV 행 수를 학생 시도 수로 해석하면 안 됩니다.

과정 로그는 별도 이해도 시험·시험지와 구분합니다. 힌트 열기·예측 제출을 실행 완료로 기록하지 않습니다. 원래 예측과 이전 시도는 불변 서버 이력에 보존하며 실측·모의·DT·수학 계산의 출처를 구별합니다.

## 검증

- `node --test artifacts/robot-control/src/*.test.cjs`: 기존 학습·운동학 회귀와 대기열/학생 분리 검증.
- `node artifacts/api-server/scripts/verify-learning.cjs`: 서버 권한·학생 분리·재접속·재전송 중복 방지·원본 보존·필터·CSV 검증.
- `node artifacts/api-server/scripts/verify-learning-browser.cjs`: 실제 입장·교수자 다운로드 UI, 연결 끊김/복구, 공용 PC 및 다른 기기 재입장 검증. 기록 기능 시험은 기존 SVG 폴백에서 하며 실물 로봇·WebGL 외부 HDR 리소스를 시험하지 않습니다.

검증 스크립트는 구별되는 TEST 수업/계정/기록만 생성하고 해당 UUID와 고유 수업 코드로 정리합니다. 실제 학생 데이터는 조회하거나 변경하지 않습니다.
