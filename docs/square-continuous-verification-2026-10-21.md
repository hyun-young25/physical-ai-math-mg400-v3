# 사각형 가상 → 실제 연속 실행

## 원인

기존 실제 실행은 DT 완주·닫힘·복귀뿐 아니라 비교/성찰 완료와 7단계 진입까지
필요했고, 접힌 ‘추가 측정’ 영역의 별도 실행 버튼과 별도 승인을 통해서만
호출됐다. 가상 완료 콜백에는 실제 실행으로 이어지는 경로가 없었다.
일부 연결 상태는 사각형 가상 실행 자체도 잠갔다.

## 변경한 흐름

1. 기존 문항 판정과 허용 오차 0.1로 확인한 학생 좌표를 저장한다.
2. 사각형 4단계에서 기존 **가상 전용 실행** 또는 명시적인
   **가상 → 실제 사각형 연속 실행 · 시작 전 확인**을 선택한다.
3. 연속 실행은 시작 전에 실제 로봇 모드·연결·서보·최신 실측·준비 설정·작업
   범위를 검사한다. 현재 학생 경로의 모든 좌표, 적용 속도, User/Tool, 설치,
   TCP·펜·작업면·장애물·물리 비상정지 확인을 표시하고 사람이 승인한다.
4. 승인 후 가상 FK/IK 애니메이션만 실행한다. 이 단계에서는 장비 이동 명령을
   보내지 않는다. 가상 전용 실행은 장비가 없어도, 연결되어 있어도 가능하다.
5. 이번 답안/과제/경로의 완주·닫힘·실행 전 자세 복귀를 실제로 확인해야만
   일회성 승인을 다음 단계로 넘긴다. 실패/중단/미완주는 넘기지 않는다.
6. 물리 명령 직전에 연결 세대, 연결 대상, 적용 설정, 설치/속도 입력의 불변성과
   최신 실측·서보·오류·정지·작업 범위를 재검사한다.
   기존 세션은 개별 명령 전에도 같은 장비 조건과 각 목표를 검사한다.
7. 추가 클릭이나 중간 비교/성찰 없이 **동일한 학생 경로 1회**를 실행한다.
   경로 1회는 기존 P1 접근과 네 변의 **5개 이동 명령**이다.
   실제 실행 단계는 가상 애니메이션을 멈추고 기존 실측 완료 피드백으로 DT를
   갱신한다. 물리 경로 기록에는 직전 가상 화면 좌표를 섞지 않는다.
8. 두 실행이 끝난 결과에서 기존 관찰·비교·성찰 학습을 계속한다.
   모의 통신은 실측이 아니며 실제 장비 학습 증거로 저장하지 않는다.

오답, 답안/과제/경로/속도/설치/연결 대상 변경, 연결 단절, 장비 오류, 실측 지연,
범위 초과, 준비 미확인은 후속 실제 실행을 차단한다. 승인 폐기 이유는
답안 수정으로 화면이 초기화되더라도 표시된다. 재연결이나 오류 해제는 실행을
재개하지 않으며 새 시작과 승인이 필요하다.

반복 클릭은 동기 잠금으로, 중복 완료 통보는 단방향 일회성 상태 전이로 막는다.
연속 실행 취소, 기존 가상 중단, 공통 ‘화면 중단 요청’, 화면 이탈은 후속 실행을
폐기한다. 물리 실행 중에는 기존 장비 정지 요청을 사용하며 물리 비상정지를
대체한다고 표시하지 않는다. 가상 단계의 공통 중단은 아직 물리 명령이 없더라도
연속 실행을 취소하지만 불필요한 물리 이동/정지 명령을 새로 만들지 않는다.

## 범위와 보존

- 사각형 연속 실행과 필요한 기존 실행 계층의 선택적 대기/중단 알림만 수정했다.
  다른 도형에는 연속 실행 UI나 대기 콜백을 연결하지 않는다.
- 정답 판정·AI 질문/오답 피드백 내용·학생 좌표 계획·다른 도형·장비 브리지·
  서버·DB·인증·Secrets·패키지·게시 설정은 변경하지 않았다.
- `TutorHost.tsx`, `TutorWindow.tsx`, `TutorWindow.css`는 기존
  `saved/tutor-height-2026-10-21-01`과 동일함을 Git으로 확인했다.

## 미검증 현장 항목

실제 MG400(고정 IP `192.168.1.6`) 및 PC 브리지/펌웨어 통신, 실제 정지 시간과
도착 오차, 적용 속도, 실제 실측 기반 화면 갱신, TCP·펜 돌출량·작업면 높이·
종이 접촉·선의 닫힘·장애물/배선 여유는 현장 사람이 별도로 검증해야 한다.
가상/모의 통과는 펜 접촉과 안전 여유를 확인한 것이 아니다.
처음에는 비접촉 경로로 현장 검증하고 접촉 높이는 별도 현장 승인하에 교정한다.
모의 키보드 검사와 실제 휴대전화 키보드 검증도 구분한다.
이 작업에서는 게시·배포나 실제 장비 명령을 실행하지 않았다.
