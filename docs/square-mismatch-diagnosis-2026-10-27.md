# 사각형 예측–실행 불일치 진단 (심사 피드백 반영)

## 목적

심사 피드백의 핵심 질문은 "물리적 실행에서 생성된 데이터가 AI의 판단에 어떻게 반영되고, 그 판단이 학생의 수학적 모델 수정에 어떤 차별적 지원을 하는가"이다. 기존 사각형 과제의 AI 튜터는 실행 전 오답에 힌트를 주는 역할에 머물렀다. 실행 후 비교 화면도 학생 예측을 정답(확인값)과 비교할 뿐, 로봇이 실제로 그린 결과를 판단 근거로 쓰지 않았다.

이번 변경은 다음 순환을 사각형 과제(2.1 기초 1 포함 6개 과제)에 구현한다.

**학생 예측 → 로봇(DT) 실행 → 실행 결과로 불일치 유형 진단(규칙 기반) → 수준별 피드백 → 원인 설명 → 모델(좌표) 수정 → 재실행·재검증**

## 판단 방식 (규칙 기반, 결정적)

`artifacts/robot-control/src/squareMismatchDiagnosis.ts`

- 입력 데이터
  - 학생이 실행한 예측 좌표: P2, P3, P4, 닫힘 P1
  - 과제 조건: 시작점, 가로·세로 길이, 방향
  - DT 실행 결과: 완료 또는 도달 불가 지점
  - 실장비 실측 꼭짓점: 정답 경로만 실장비로 실행됨
  - 같은 과제의 이전 시도 이력
- 처리
  1. 로봇이 실제로 그린 네 변(ΔX, ΔY)을 과제 조건의 네 변과 비교한다.
  2. 처음 어긋난 변을 찾아 아래 유형 중 하나로 분류한다.

| 유형 | 판별 기준 (실행된 변 vs 조건) |
|---|---|
| 위치와 이동량 혼동 | 꼭짓점 좌표가 변의 이동량(또는 P1 기준 변위)과 같음 |
| 축·길이 뒤바뀜 | 변이 다른 축으로 움직였거나, 가로·세로 길이가 서로 바뀜 |
| 방향(부호) 오류 | 축과 길이는 같고 부호만 반대 |
| 닫힘 오류 | 앞의 세 변은 맞고 마지막 변이 P1로 돌아오지 않음 |
| 계산 오류 | 그 밖의 길이 차이 |
| 도달 불가 위치 | DT가 역기구학 해를 찾지 못한 지점 |
| 모형–실물 차이 | 계산·DT는 정답인데, 실장비 실측 꼭짓점이 1 mm보다 크게 어긋남 |

- 출력: 피드백 수준은 같은 과제·같은 유형의 이전 시도 횟수로 정한다.
  - 기초 지원: 1회째는 1단계(무엇이 다른지 관찰), 2회째는 2단계(관계 힌트), 3회째부터 3단계(비슷한 예시와 교사 도움 표시)이다.
  - 도전 모드: 한 단계 늦게 올라간다(지원 감소). 1·2회째는 1단계, 3회째는 2단계, 4회째부터 3단계이다.
  - 불일치를 해결한 뒤 일치하면 "다음 과제에서 어떻게 미리 점검할까요?"라는 자기조절 질문으로 마무리한다.
- 정답 좌표는 질문에 넣지 않는다. 불일치한 항목은 비교표의 확인값도 가리고 "실행 결과로 다시 계산"으로 표시한다.
- GPT 모드에서는 진단 결과(유형·근거·수준)를 전달하고 질문 1개를 2문장 이내로 문장화하게 한다. 판단은 규칙이 하고 GPT는 표현만 담당한다. GPT가 실패하면 규칙 기반 질문이 그대로 남는다.

## 화면

- 6단계(비교·해석) 상단에 "실행 결과와 과제 조건 비교" 패널을 표시한다.
  - 변별로 과제 조건과 로봇이 그린 변을 나란히 보여 주고, 처음 어긋난 변을 강조한다.
  - 수준에 맞는 질문 1개를 보여 준다.
  - 2단계부터 관계 힌트, 3단계에서 예시와 교사 도움 요청 표시를 더한다.
- "차이가 생긴 이유"를 적어야 "이유 저장 · 예측 고쳐 다시 실행" 버튼이 켜진다. 누르면 좌표 입력(3단계)으로 바로 돌아가 다시 예측 → DT 실행 → 비교한다.
- AI 수학 튜터 창이 자동으로 열리고 같은 질문을 "실행 결과 비교 · n단계"로 보여 준다.
- 실장비 실행 후 실측 오차가 1 mm를 넘으면 측정 결과 아래에 모형–실물 차이 패널을 띄운다. 학생의 설명은 측정으로 확인된 원인이 아니라 가설로 기록한다.

## 기록 (연구 자료)

학습 기록(`InquiryRecord`)에 `mismatchDiagnoses[]`를 추가했다. 기존 동기화와 교사 CSV에 자동으로 포함되며, CSV에는 `mismatchDiagnoses[0].type` 같은 항목 경로로 나타난다. 실행마다 아래 항목을 남긴다.

- 진단 정보: `type`, `edge`, `label`
- 피드백 정보: `level`, `question`, `relationHint`, `teacherFlag`
- 조건: `supportMode`, `priorSameType`, `source`(dt 또는 hardware)
- 근거 수치: `evidence`(조건·실행된 변·실측 오차)
- 학생 응답: `causeExplanation`, `explainedAt`

## 안전·기존 동작

- 오답 경로로는 여전히 실장비를 실행할 수 없다. 도전 모드의 오답은 DT에서만 실행된다.
- 연결·작업 범위·실행 승인·연속 실행 검사는 변경하지 않았다.
- 삼각형과 원, 다른 과제의 동작은 변경하지 않았다.
